# RTB Storefront

Premium frontend-only RTB fashion ecommerce prototype, built with Next.js, Tailwind CSS v4, Phosphor Icons and a Taste Skill-inspired anti-slop design direction.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Scope

Frontend only. Products are mock data. Cart uses localStorage. Checkout is a simulated flow. Replace image URLs and product data with RTB's real catalogue before launch.

## Design read

Premium consumer fashion storefront for design-conscious shoppers, using an editorial, high-contrast, restrained fashion language. Dials: DESIGN_VARIANCE 7, MOTION_INTENSITY 5, VISUAL_DENSITY 3.

The AlShal reference informed the ecommerce information architecture only. No AlShal branding, copy, code, or assets are used.
